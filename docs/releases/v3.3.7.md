# Orbit SSH v3.3.7

精简终端界面，并改善服务器监控的局部容错与失败诊断。

## 更紧凑的终端工作区

- 移除顶部重复的「终端会话」标题栏，让终端获得更多垂直空间。
- 深色／浅色模式切换移到侧边栏底部，侧边栏收窄后仍可使用；窄屏导航入口合并到工作区标签栏。
- 移除终端工具栏中的全局显示设置和粘贴按钮，保留偏好设置入口及快捷键粘贴。

## 监控容错与错误提示

- CPU、内存、网络速率、磁盘容量、磁盘 I/O、进程及系统信息分别处理采集失败；某项失败不再导致其他成功指标无法显示。
- 失败项显示「未获取」及具体原因，避免将缺失值当成真实的 0；网络和磁盘 I/O 失败时不再默默隐藏区块。
- 保留远端错误，针对权限不足、命令缺失、参数不兼容、额外 SSH 通道被拒和超时提供排查提示。
- 远端提供 `timeout` 时，单项采集限时 2 秒；整轮限时 8 秒，超时后保留已完整接收的指标。
- 整轮失败时保留上次成功数据，明确显示采样时间及「非当前数据」，并继续自动重试。
- CPU、内存趋势在失败处断开，不把缺失值绘制为 0；没有温度传感器的虚拟机不会仅因此报警。

监控仍面向 Linux，使用当前 SSH 登录账号，通过独立命令通道只读采集，不要求 root，也不会自动执行 sudo。服务器需要允许额外的 session 通道及非交互命令执行。
