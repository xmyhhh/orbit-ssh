# Orbit SSH v1.0

Orbit SSH 的首个正式版本：在一个桌面窗口中连接服务器、使用多终端、传输与编辑文件、查看 Linux 服务器状态，也可以直接打开本机 WSL。

无需注册账号，主机配置和凭据保存在本机，适合个人日常使用。

## 下载与开始使用

**[下载 OrbitSSH-v1.0-windows-x64.exe](https://github.com/xmyhhh/orbit-ssh/releases/download/v1.0/OrbitSSH-v1.0-windows-x64.exe)**

本次仅提供 **Windows x64** 可执行文件，无需安装 Orbit SSH，下载后双击即可运行。GitHub 自动提供的 Source code 压缩包是源码，不是桌面应用。

运行需要 **Microsoft Edge WebView2 Runtime**，Windows 11 通常已自带。若提示缺少组件，请先从[微软官网](https://developer.microsoft.com/microsoft-edge/webview2/#download)安装 Evergreen Runtime。

首次打开后，点击「新建连接」，填写服务器地址、端口和用户名，选择密码或私钥认证。核对首次连接显示的服务器指纹后，即可进入终端。完整操作说明见[使用指南](https://github.com/xmyhhh/orbit-ssh/blob/v1.0/README.md)。

## v1.0 提供的功能

### 服务器与多终端

- 按分组整理主机，支持收藏、搜索和最近连接。
- 首页默认卡片视图，可切换为紧凑列表，并记住你的选择。
- 支持密码和 PEM / OpenSSH 私钥认证，可保存密码与加密私钥口令。
- 首次连接核对 SHA-256 指纹，后续自动验证，指纹变化时拒绝连接。
- 每台主机拥有独立标签，同一主机可开多个终端，关闭单个终端不影响其余会话。

### 更顺手的终端操作

- 支持搜索终端输出、右键菜单，以及系统剪贴板复制粘贴。
- 有选中文本时 `Ctrl + C` 复制，无选中时保持命令中断行为；`Ctrl + V` 粘贴，多行内容先确认。
- 使用 `Ctrl + Shift + T` 新建终端，`Ctrl + Shift + F` 搜索输出，`Ctrl + 滚轮` 调整字号。
- 内置 40 条常用 Linux 命令片段，支持分类、搜索、自定义和编辑；插入终端后按 Enter 执行。
- 支持浅色、深色和跟随系统，可调整终端字号与行距。

### 文件传输与远程编辑

- 双栏浏览本地和远程文件，支持多选、新建文件夹和隐藏文件显示。
- 上传、下载文件及整个文件夹，队列显示进度、速度和失败原因，支持取消。
- 同名文件默认跳过，也可选择替换；切换标签时后台传输继续。
- 双击远程文本即可编辑，支持语法高亮、查找替换、撤销、自动换行和 `Ctrl + S` 保存。
- 关闭未保存文件时提醒，保存失败或检测到远端文件变化时保留当前修改。

### Linux 服务器监控

- 查看 CPU、内存、交换空间、磁盘和进程列表。
- 支持 3 / 5 / 10 秒刷新间隔、手动刷新和暂停，窗口隐藏时暂停采样。
- 通过 SSH 只读采样，无需安装专用监控代理。

### 本机 WSL 终端

- 自动发现已安装的 WSL 发行版，无需 SSH 服务或密码即可打开终端。
- 同一发行版支持多个独立会话，可使用搜索、复制粘贴和字号缩放。
- 关闭标签只结束当前会话，不会关闭整个发行版。

## 数据保存与更新

主机、命令片段、偏好和已信任指纹保存在 `%APPDATA%\OrbitSSH\workspace.json`。密码和私钥口令存放于 Windows 凭据管理器，不写入该 JSON；私钥保留在原始文件位置。

使用过早期版本的用户，可退出旧版后直接运行新版，继续使用本机配置。建议更新前备份配置文件；该备份不包含凭据库中的密码或私钥文件。

## 使用前请了解

- **平台**：本次仅提供 Windows x64，不提供 ARM64、32 位或其他系统的安装包。
- **WSL**：需先安装 WSL 和发行版；内嵌终端需要 Windows 10 1809 或更新版本。v1.0 的 WSL 功能为终端，文件管理和监控用于 SSH 连接。
- **文件传输**：服务器需启用 SFTP；暂不支持断点续传，符号链接和特殊文件跳过。关闭连接或退出应用会中断传输。
- **远程编辑**：支持不超过 2 MB 的 UTF-8 文本，需要目标目录的写入与重命名权限，不支持 sudo 保存。替换保存不复制原文件的 ACL、扩展属性及硬链接关系。
- **监控**：目前支持 Linux，依赖 `/proc`、`df` 和 procps 的 `ps`。CPU 使用率在第二次采样后显示；进程 CPU 是生命周期平均值，多核时可超过 100%。
