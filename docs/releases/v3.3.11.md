# Orbit SSH v3.3.11

服务器指纹变化时，可以直接在连接对话框里清除旧记录并重新连接，随后再核对新指纹。

## 连接对话框内清除旧指纹

- 连接被拒绝时，分别显示已保存的指纹和服务器当前指纹，不再显示原始的 `HOST_KEY_CHANGED` 文本。
- 点击「清除旧指纹并重新连接」会删除这台主机的旧信任记录并立即重试。
- 重连后仍会显示服务器当前指纹，必须核对后点击「信任并连接」，不会跳过或自动信任。
- 如果变化发生在跳板机上，会提示先单独连接跳板机并在其主机设置中清除，不会误清目标主机的记录。
- 主机编辑窗口中的「清除已信任指纹」继续保留，两条路径效果一致。
- 已经建立的终端会话保持连接，只有后续握手需要重新信任。

服务器重装系统或更换 SSH 主机密钥后，先通过云控制台或管理员核实新指纹，再点击清除并重新连接即可。

## 验证与发布

- 浏览器测试覆盖指纹变化提示、清除旧记录、自动重连到新指纹确认页。
- 前端类型检查、生产构建、现有单元测试、Go 测试和 Android 桥接测试通过。
- CI 在 Windows x64、macOS（Apple Silicon / Intel）、Linux x64 四个节点完成测试和打包，全部成功后发布 Release。
- 从旧版本覆盖安装会保留主机、密码、私钥口令和已有指纹记录。
