# Orbit SSH v3.3.8

SSH 断开后，直接在原终端重新连接，不再额外新建标签。

## 原地重新连接

- 保留原终端的标签、名称、编号、已有输出、历史记录和分屏位置。
- 重连期间显示连接状态并防止重复建连；失败或取消后保留原终端，允许再次重试。
- 继续使用正常的密码、私钥口令和服务器指纹验证，不绕过身份校验。
- 在新 Shell 输出之前显示重连分隔提示，避免覆盖提示符；从断开的全屏程序退出到正常终端模式，不清空原有回滚输出。
- 不自动重放旧连接中排队的输入；旧 Shell 的 AI 完全放行授权不会自动延续到新连接。

**这是新建 SSH / Shell 连接，不是恢复旧 Shell。** 上次目录、临时环境变量和前台任务不会自动恢复；需要断网保活的任务请预先使用 `tmux` / `screen`。本地 Shell / WSL 的「重新打开」行为不变，本次未加入自动重连或目录恢复。

## 验证

- 新增浏览器回归测试，覆盖原地重连、输出与名称保留、分屏几何、失败重试、取消、密码和指纹验证、全屏程序断开及远端立即退出。
- 本地 SSH 服务集成测试覆盖断线、认证失败后的同 ID 重连、终端输入、窗口尺寸及 SFTP 恢复。
- GitHub CI 在各桌面构建节点运行前端和 Go 测试，Linux 额外执行浏览器重连测试；全部通过后才发布。
