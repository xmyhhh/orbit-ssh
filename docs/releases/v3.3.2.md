# Orbit SSH v3.3.2

## MCP 审批与单终端放行

- `send_terminal_input` 包含换行（`\n`）或回车（`\r`）时，与 `run_command` 一样先请求审批；不含换行的交互文本直接输入。
- MCP 服务运行且允许终端输入时，可从终端工具栏手动开启当前终端的「完全放行」。放行只在当前会话有效，不会持久保存；新终端默认仍需审核。
- `list_sessions` 返回 `unrestricted` 状态，工具说明建议 AI 在没有特殊需求时优先使用已放行终端。

## 系统通知

- 新增 macOS、Windows、Linux 审批通知实现，通知发送失败不会阻塞应用内审批。
- macOS 和 Linux 通知支持打开应用、允许和拒绝操作；Windows 通知用于提醒，审批仍在应用内完成。
- 已处理、取消或超时的请求会清理通知及回调，避免重复执行或操作失效请求。

通知显示受系统权限、勿扰模式和桌面通知服务影响；本轮已完成本地测试及跨平台编译检查，但尚未完成三平台原生桌面通知显示与点击闭环实测。

## 弹窗修复

- 审批弹窗简化为控制台名称、完整命令和拒绝/允许操作，高风险内容显示「高风险」标记。
- 修复浅色主题下命令文字不清晰的问题，长命令可滚动查看。
- 审批超过 2 分钟、请求取消或已处理时自动关闭；点击「× / 拒绝」立即收起，不再被后端“请求不存在或已处理”错误卡住。
- 增加待审队列校验、恢复焦点校验和过期时间处理，补齐审批并发、失效及界面回归测试。

## macOS 更新注意

更新前请从菜单栏选择「退出 Orbit SSH」，确认应用进程结束后，再用安装包中的完整 `.app` 替换旧版。仅关闭窗口仍会在后台运行。不要在运行时单独覆盖 `Contents/MacOS/OrbitSSH` 或重新签名旧应用包，否则可能触发系统的 `CODESIGNING / Invalid Page` 强制终止。
