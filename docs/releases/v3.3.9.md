# Orbit SSH v3.3.9

在应用内查看 GitHub 新版本与发布说明，文件传输失败后可直接重试。

## 检查更新与发布说明

- 点击左下角版本号打开「关于 Orbit SSH」，手动检查最新正式版本。
- 直接读取本项目 GitHub Releases，展示版本、发布日期和发布说明，无需账号或 Token。
- 按当前系统和程序架构展示安装包：Windows 可选择安装版或便携版，macOS 提供 DMG / ZIP，Linux 提供压缩包。
- 点击下载按钮会打开系统浏览器；下载完成后退出应用，再安装或替换。
- 检查超时为 15 秒，成功结果缓存 5 分钟；网络失败或 GitHub 限流时提供提示及发布页入口。
- 修正版本号显示，完整保留补丁版本，并按数值比较版本号，正确识别 `3.3.10` 高于 `3.3.9`。

## 文件传输一键重试

- 失败或已取消的传输任务可直接点击右侧重试按钮。
- 沿用原来的源文件、目标目录和「跳过／替换」设置；切换浏览目录不会改变重试目标。
- 重试创建新任务并保留原记录；提交过程中禁用重复点击，断线时需先在原终端重新连接。
- 单个文件从头传输；使用「跳过」时保留已完成的同名文件，使用「替换」时重新覆盖。

## 验证与发布

- Go 测试覆盖版本比较、GitHub 响应及错误、缓存、平台附件选择，以及上传／下载重试、取消和文件冲突处理。
- 浏览器测试覆盖检查更新、发布说明、外部下载、失败重试、传输重试与重连。
- CI 校验完整版本号，在四个桌面构建节点完成测试和打包，Linux 额外运行浏览器及并发检查；全部成功后发布 Release。
