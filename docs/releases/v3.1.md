# Orbit SSH v3.1

v3.1 把 Orbit SSH 从 Windows 桌面版扩展到 macOS 和 Linux：三个桌面平台共用同一个后端，都支持本地 Shell、系统托盘和后台常驻。Android 端的会话在应用退到后台后继续运行，这一改动会在下个 Android 版本单独发布。

## macOS 支持

- 菜单栏图标取代系统托盘：点击窗口关闭按钮后应用隐藏到菜单栏，会话和传输继续运行，从菜单栏图标可以恢复窗口或退出。
- 菜单栏图标优先使用 SF Symbols，低版本 macOS 回退为自绘的模板图标；菜单操作统一切回主线程，避免阻塞界面。
- 本地 Shell 使用伪终端运行登录 Shell 以及 zsh、bash、sh、fish、tcsh、csh、ksh，多个终端互相独立。
- 密码与私钥口令存入钥匙串，主机配置和终端历史保存在 `~/Library/Application Support/OrbitSSH`。
- 新增 `scripts/build-macos.sh`，可构建 Apple Silicon、Intel 和通用二进制，并完成临时签名与打包；App 的 Bundle 标识符固定为 `io.orbitssh.macos`。

## Linux 支持

- 按 StatusNotifierItem 规范实现的系统托盘，使用纯 Go 的 D-Bus 客户端，不引入 cgo，也不占用 GTK 主循环。KDE Plasma 原生支持，GNOME 需要安装 AppIndicator 扩展，否则看不到托盘图标，窗口行为不受影响。
- 本地 Shell 复用 macOS 的伪终端实现，Shell 列表覆盖常见发行版自带的 bash、sh、dash、zsh、fish 等。
- 密码与私钥口令保存在 Secret Service，需要系统提供 `org.freedesktop.secrets`；GNOME 之外的系统可能需要安装 `libsecret` 与 `gnome-keyring`。
- 构建改用 WebKitGTK 4.1 ABI，Ubuntu 24.04 和 Debian 12 才能正常链接。

## Android 后台会话

- Go 引擎改为单例进程，由前台服务托管，关闭窗口或划掉应用都不会结束会话和传输。
- 引擎把活动的会话数报告给宿主，由宿主启停服务和常驻通知；报告设有短超时，宿主无响应时不会卡住正在启动的会话。
- 域名解析交给宿主处理，适配 Android 私有 DNS、VPN 和网络切换；Keystore 凭据库同样移入引擎，没有界面时也能工作。

## 内部整理

- Go 源码按功能拆到 `src/` 下：应用主体在 `src/app`，平台能力、本地终端、系统托盘、SSH Agent、MCP 客户端配置和 Android 管道协议各自成包，仓库根目录只保留 Wails 需要的入口。
- 绑定方法必须和 `App` 结构体同包，所以对外方法仍集中在 `src/app`；前端调用路径由 `window.go.main.App` 改为 `window.go.app.App`。
- 修复关闭确认的测试和保活协程的数据竞争，并让发布脚本在 `gh` 输出告警时不再中断发布。
