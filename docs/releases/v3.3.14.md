# Orbit SSH v3.3.14

主机连接新增代理设置，可以通过 Clash 等支持 SOCKS5 或 HTTP CONNECT 的代理连接 SSH 服务器。

- 在主机的「连接设置 → 连接代理」中选择 SOCKS5 或 HTTP CONNECT，填写代理地址和端口。例如 Clash 本机混合端口常见为 `127.0.0.1:7890`，请以实际设置为准。
- 目标域名由代理解析；SSH 主机指纹仍需核对。终端、SFTP 和 SSH 隧道使用建立的 SSH 连接。
- 连接代理与跳板机不能同时使用，已启用连接代理的主机不能作为跳板机。当前支持无认证代理。
- 修复偏好设置中较长说明挤压开关的问题。

旧主机默认继续直连，原有主机、凭据和设置会保留。
