# Orbit SSH v3.2

## 改进

- 终端在支持 WebGL2 的设备上优先使用 GPU 渲染，改善快速滚动大量终端内容时的绘制性能。
- WebGL2 初始化失败或图形上下文丢失时自动回退到默认渲染器；多个终端之间切换时仅焦点终端持有 WebGL 上下文。
