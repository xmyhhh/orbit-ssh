## SSH 隧道与 X11

- 主机设置新增「SSH 隧道」页，可保存本地、远程及动态 SOCKS5 TCP 转发，逐条启停、编辑或删除。
- 同一主机的多个终端共享转发，最后一个终端关闭后释放；端口冲突或服务器拒绝时提示错误并回收已启动的规则。
- SOCKS5 支持服务器侧域名解析；默认监听 `127.0.0.1`，远程对外监听仍受 SSH 服务器 `GatewayPorts` 限制。
- X11 支持 DISPLAY 和 Xauthority 配置，为每个 SSH 会话生成独立 cookie，验证并替换为本机认证信息。需另行启动本机 X Server，并在 SSH 服务器开启 X11 转发及安装 `xauth`。

## 终端工作区与历史

- 拖动标签组合分屏，每组最多 4 个窗格，支持调整比例、交换窗格及多个独立分屏标签。
- 切换标签保留各组布局、焦点和连接；解除分屏或收起窗格保留会话。
- 终端历史保存在当前设备，支持搜索、精选、删除及保留数量设置。
- Windows 可直接打开 PowerShell、CMD、PowerShell 7 和 WSL；关闭窗口默认常驻托盘，保留终端与传输。

## MCP 与 AI 客户端

- Windows 可启用本机 Streamable HTTP MCP 服务，让 AI 读取活动终端、搜索历史，或经授权创建主机、打开 SSH 会话及输入命令。
- 一键接入 Codex、Claude Code、Cursor、OpenCode、Gemini CLI 和 VS Code Copilot，也支持 EXE 的 `install` 命令。
- 合并现有 TOML / JSON / JSONC 配置，保留其他设置及注释，修改前备份，重复接入不重复写入。
- 创建连接与终端输入权限独立，默认关闭；服务仅监听本机并要求访问令牌。

## Android

- 复用 Go SSH / SFTP 引擎，支持主机管理、指纹校验、密码与私钥认证、文件传输、远程编辑和监控。
- 支持手机全屏、分屏、终端切换、软键盘辅助按键、原生选择菜单、双指缩放和主题系统栏。
- 支持从系统导入文件、将下载导出到手机；密码和私钥口令使用 Android Keystore 加密保存。
- 本次 APK 为 ARM64，主要面向前台使用；系统回收应用或强行停止会结束会话和传输。

## 升级与说明

Windows 退出旧版后运行新 EXE，可继续使用原有配置和系统凭据。Android 相同签名的 APK 可覆盖安装；自行构建的旧版需要沿用原签名。Windows 与 Android 的配置分别保存。

完整操作说明和新版截图见 [README](https://github.com/xmyhhh/orbit-ssh/blob/v2.0/README.md)，手机操作见 [Android 说明](https://github.com/xmyhhh/orbit-ssh/blob/v2.0/docs/ANDROID.md)。

文件传输需要 SFTP；远程编辑面向不超过 2 MB 的 UTF-8 文本，不提供 sudo 保存。服务器监控面向 Linux。暂未提供 macOS、Linux、Windows ARM64 或 Android x86 安装包。
