# Orbit SSH v3.3.5

修复分屏终端切换焦点后，另一侧窗格文字消失、显示空白的问题。

## 分屏渲染修复

- WebGL 渲染器跟随窗格可见性管理，点击其他窗格不再卸载仍然可见的终端渲染器。
- 窗格从隐藏或最大化状态恢复时，重新适配终端尺寸并刷新画面。
- 保留终端会话和缓冲区，隐藏期间的输出在恢复后继续显示。
- 新增渲染生命周期回归测试。
