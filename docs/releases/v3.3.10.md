# Orbit SSH v3.3.10

在主机设置中查看并清除已信任的服务器指纹，服务器重装或更换 SSH 主机密钥后无需再手动编辑配置文件。

## 清除已信任指纹

- 编辑主机时，「连接设置」会显示当前已保存的 SHA-256 服务器指纹。
- 点击「清除已信任指纹」后需要二次确认，避免误操作；清除只影响这台主机自己的指纹记录。
- 清除后，下次连接会重新显示服务器指纹并要求核对，不会跳过任何身份校验。
- 已经建立的终端会话保持连接，只有后续握手需要重新信任。
- 跳板机的信任记录独立保存，不会随目标主机的清除操作一起删除。

重装服务器、更换 SSH 主机密钥或迁移到新机器导致提示「服务器指纹与之前保存的记录不同」时，先通过可信渠道核实新指纹，再在主机编辑窗口清除旧记录，重新连接并确认新指纹即可。仍需手动编辑 `workspace.json` 的场景不再需要。

## 验证与发布

- Go 测试覆盖指纹查询、清除、重复清除、持久化和不影响其他主机信任；Android 桥接测试同时验证新接口。
- 前端类型检查、生产构建和现有单元测试通过。
- CI 在 Windows x64、macOS（Apple Silicon / Intel）、Linux x64 四个节点运行测试与打包，全部成功后发布 Release。
- 从 v3.3.9 覆盖安装会保留主机、密码、私钥口令和已有指纹记录。
