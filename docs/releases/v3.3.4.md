# Orbit SSH v3.3.4

修复 Codex 无法加载 Orbit SSH MCP 工具的问题。Codex 现在通过本机 stdio 桥接连接 Orbit SSH，不受 HTTP 代理对回环请求的影响；其他 MCP 客户端继续使用 HTTP 接入。

## MCP 接入修复

- Codex 使用 Orbit SSH 启动程序运行本机 stdio 桥接，自动读取 MCP 端口和令牌，不需要在 Codex 配置中保存访问令牌。
- 一键接入、命令行接入和手动配置片段统一生成 Codex stdio 配置。
- 其他客户端仍使用原有的 Streamable HTTP MCP 接口。
