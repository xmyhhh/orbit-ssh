# Orbit SSH v3.3.12

集成设置新增 AI 命令直接执行选项：启用后，之后打开的终端默认完全放行；已打开终端的授权状态不会被修改。

## AI 命令执行

- 在「偏好设置 → 集成」新增「允许 AI 直接执行命令」。
- 该选项与「允许 AI 输入终端」及 MCP 服务共同生效；需要同时启用，AI 才能在新终端中免逐条审批执行命令。
- 新开终端会按当时的设置取得会话级授权；之后更改默认选项不会更改已有终端的授权。
- 每个终端关闭后授权即失效，不会持久保存。未启用此选项时仍按原流程逐条审批，也可在终端工具栏单独切换当前会话。

## 验证与发布

- Go 测试覆盖默认授权所需权限、新终端继承默认授权、已有终端授权保持不变，以及免审批命令执行。
- 前端类型检查、生产构建、前端测试和 Go 测试通过。
- CI 在 Windows x64、macOS（Apple Silicon / Intel）、Linux x64 四个节点完成测试和打包，全部成功后发布 Release。
- 从旧版本覆盖安装会保留现有主机、凭据和设置；新增选项默认关闭。
