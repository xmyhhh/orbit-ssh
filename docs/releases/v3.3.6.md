# Orbit SSH v3.3.6

修复 macOS 关机／重启被 Orbit SSH 中断的问题，并为 Windows、Linux 统一关机、注销与主动退出机制，新增远程编辑的本机恢复草稿。

## 关机与退出

- 关闭窗口继续遵循「关闭到托盘」偏好，保留会话和编辑内容；托盘不可用时不再将窗口隐藏到不可访问的后台。
- 主动退出应用仍可确认或取消；未保存的远程修改会提示，活动会话遵循关闭确认偏好。
- 系统关机、重启、注销不再因后台 SSH 会话或关闭到托盘逻辑被否决，也不弹阻塞式会话确认。
- 清理使用 3 秒总预算，并行关闭连接、终端及后台服务；慢连接不会逐个累加关机等待时间。
- macOS 修复 AppKit 退出握手，区分 Command-Q／Dock 主动退出与系统退出，并处理已有确认框与关机请求并发的情况。
- Windows 增加独立的系统会话通知窗口，不依赖托盘图标或 Explorer；查询阶段不提前断开会话，系统提交退出后才清理。
- Linux 接入 logind 关机通知、GNOME 注销协议及 SIGTERM／SIGINT 兜底；缺少相应桌面服务时采用尽力清理，不申请无限期阻止关机的锁。

## 本机恢复草稿

- 远程编辑过程中持续保存本机恢复副本；重新连接同一主机、打开同一路径时，可选择恢复或丢弃。
- 恢复不会自动上传或覆盖服务器文件，保存时仍检查远程版本，避免覆盖其他人的修改。
- 草稿与远程保存分离，远程网络请求卡住不会阻止本机草稿持久化；存储失败会显示提示。
- 支持 Windows 风格远程路径，补齐共享 Android 编辑器的草稿 API 兼容性。
- 草稿是当前用户配置目录内的明文文件，可能包含敏感内容；强制结束、断电、磁盘故障或最后一次自动保存前的输入不保证恢复。

详细策略、平台限制和验收步骤见 [关机、退出与恢复机制](https://github.com/xmyhhh/orbit-ssh/blob/v3.3.6/docs/SHUTDOWN.md)。重要远程长任务仍建议使用 tmux、screen 或服务管理器；文件传输不会自动续跑。
