## 界面统一

- 全部 14 处下拉框（新建主机、跳板机、所属分组、转发类型、终端行距、保活间隔、MCP 客户端、监控刷新间隔、进程排序、发送信号、同名文件处理、语法高亮、切换终端、工作流目标）改用同一套自绘控件，Windows 上不再出现系统灰白弹层。
- 下拉支持键盘操作：方向键移动、Home / End 跳转、Enter 选中、Esc 关闭、首字母快速定位；弹层靠近屏幕边缘时自动上翻，长列表可滚动。
- 所属分组支持在弹层内搜索并直接新建分组，不再依赖系统输入建议。
- 统一了偏好设置的标签栏宽度、设置项控件高度、小号按钮高度，以及主机页、终端历史页和侧栏的搜索框样式。
- 设置行的数值输入框补齐边框、圆角和聚焦态，数字输入在 Windows 下不再显示多余的系统按钮。

## 快速搜索

- 侧栏「搜索或快速切换」更名为「**快速搜索**」，`Ctrl / ⌘ K` 打开的弹窗同步更名。
- 一次搜索同时覆盖三类内容，并按「主机 / 工作流 / 终端历史」分组展示，命中数量显示在分组标题上：
  - 主机：名称、地址、用户名、分组。
  - 工作流：标题、说明，以及每一步的标题和命令。
  - 终端历史：主机名、终端标题和输出内容。
- 选中工作流会跳转到工作流库并选中该条；选中历史记录会跳转到终端历史并定位到该条，同时自动切换到「最近」或「精选」。

## 工作流可编辑

- 工作流库页面改为**查看与编辑**界面：不再显示「执行此步」「标记完成」「跳过」等运行态按钮，保留右上角「选择主机执行」进入执行流程。
- 每一步的命令都可以复制、直接修改、删除；修改会立即写入工作流定义，并同步清除该步骤的临时命令覆盖。
- 可以手动添加步骤，添加后直接填写标题和命令；删除步骤会一并清理其他步骤对它的前置引用。
- 终端里的工作流面板改用下拉框选择流程，替换了原先浮在标题栏下方的列表。
- 命令区支持选中文本，工作流面板内也提供复制按钮。

## 内置工作流

内置 6 条可直接使用、也可继续编辑的工作流：

| 工作流 | 步骤 | 用途 |
| --- | ---: | --- |
| 检查并更新 Nginx 配置 | 6 | 语法检查、查看配置、编辑、验证、重启、确认状态。 |
| 磁盘空间清理与日志轮转 | 5 | 排查占空间目录、清理过期日志、轮转压缩、复查水位。 |
| 服务健康巡检 | 4 | 只读巡检服务状态、错误日志、监听端口和资源占用。 |
| Docker 容器维护 | 6 | 清理悬空镜像和停止的容器，重启指定容器并确认。 |
| TLS 证书与跳转检查 | 4 | 检查证书有效期、签发者、HTTP 跳转和 443 可达性。 |
| 系统更新与重启 | 4 | 拉取更新、升级系统、按需重启并验证。 |

内置工作流可以删除，删除后不会再次出现；对内置工作流所做的修改会被保留。

## 终端历史搜索

- 搜索范围扩展到「最近」和「精选」的全部记录，命中行会标注来源，不再出现「明明有记录却搜不到」的情况。
- 匹配改为按空格分词后逐词命中，中文按字匹配；顺序匹配限制在紧密窗口内，避免在长输出里误命中。
- 命中的标题、副标题、输出预览和详情面板都会高亮；搜索时自动选中第一条结果，右侧详情不再变空白。
- ANSI 转义剥离和检索索引改为只计算一次并延迟渲染，在大体积输出下打字不再卡顿。

## 私钥选择校验

- 选择或填写以 `.pub` 结尾的公钥文件时会立即提示「这是公钥文件（.pub），私钥登录需要选择不带 .pub 后缀的私钥文件」，并阻止保存。
- 校验同时在后端执行，覆盖界面保存、SSH 配置导入和 MCP `create_host` 三条路径。

## 升级与说明

Windows 退出旧版后运行新 EXE，可继续使用原有配置和系统凭据。安装版按当前用户安装，卸载不会删除 `%APPDATA%\OrbitSSH` 中的主机配置、凭据和终端历史。

完整操作说明和新版截图见 [README](https://github.com/xmyhhh/orbit-ssh/blob/v3.0/README.md)。

文件传输需要 SFTP；远程编辑面向不超过 2 MB 的 UTF-8 文本，不提供 sudo 保存。服务器监控面向 Linux。暂未提供 macOS、Linux、Windows ARM64 或 Android 安装包。
