# Orbit SSH v3.3.13

使用 AI 执行命令时，可以在审批弹窗中看到 AI 填写的一句话执行原因，确认更有依据。

## AI 说明

- 审批弹窗新增「AI 说明」区域，显示 AI 附加的简短执行原因；留空或未提供时该区域不出现。
- `run_command` 与 `send_terminal_input`（文本包含换行或回车、需要审批时）新增可选参数 `reason`。
- 原因由 AI 自行填写，弹窗仍展示完整命令和拒绝/允许操作，高风险标记不变。
- 系统通知的正文也会带上原因，方便在窗口外快速判断。
- 该说明仅作参考，命令本身仍以弹窗中的完整内容为准。

## 长度限制

- 中文原因限制在 35 个字符内（含中日韩文字时按字符计算）。
- 英文原因限制在 35 个单词内。
- 超出限制时工具直接返回错误，例如「reason 过长：必须简短于 35 个单词（当前 47 个），请写得更简短」，不会进入审批队列。
- 多行或多余空白会被折叠成一行；控制字符会被拒绝。
- 参数说明已写入 MCP 工具的 inputSchema 描述，AI 客户端可直接读到限制与「可为空」。

## 验证与发布

- 新增 Go 测试覆盖中文/英文边界、超限报错、空原因、事件与列表一致性、完全放行终端、以及工具 schema 描述。
- 前端测试覆盖说明区块仅在存在原因时渲染及配色对比度。
- 前端类型检查、生产构建、前端测试、Go 测试、Android 桥接测试和 `go vet` 通过。
- CI 在 Windows x64、macOS（Apple Silicon / Intel）、Linux x64 四个节点完成测试和打包，全部成功后发布 Release。
- 从旧版本覆盖安装会保留现有主机、凭据、设置和终端历史；不填写原因时弹窗与旧版本完全一致。
