# Orbit SSH v3.3

## 修复

- 修复 macOS 版的安装包无法打开的问题。CI 之前没有给 App Bundle 做整体签名，浏览器下载后带 quarantine 标记的系统会判定为损坏，提示「Orbit SSH 已损坏，无法打开」。现在 CI 会在打包前完成签名；仓库配置开发者证书后还会一并公证，下载后无需任何放行操作。

## 改进

- macOS 版新增 dmg 磁盘映像，双击 dmg 后把 `Orbit SSH.app` 拖进「应用程序」即可安装，映像里附带安装说明和许可证。
- 主机卡片新增右键菜单，可直接重命名、复制、打开连接和删除主机。
- 设置页与主机交互的细节调整：终端分屏、主机分组与搜索的结果更稳定。

macOS 另外提供 zip 格式：`OrbitSSH-v3.3-macos-arm64.zip` 与 `OrbitSSH-v3.3-macos-x64.zip`，内容与 dmg 内的 App 相同。

本次 Release 仅包含桌面版。Android ARM64 仍使用 [v2.0 APK](https://github.com/xmyhhh/orbit-ssh/releases/download/v2.0/OrbitSSH-v2.0-android-arm64.apk)。下载后可通过发布附件中的 `SHA256SUMS.txt` 校验文件。

macOS 用户首次打开若提示「Apple 无法验证…是否包含恶意软件」，在终端执行 `xattr -dr com.apple.quarantine "/Applications/Orbit SSH.app"` 清除下载标记，或右键点击 App 选择「打开」即可；更新版本后同样需要再执行一次。
