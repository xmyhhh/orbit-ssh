# 终端标签与手机全屏

拖动独立终端标签到另一个终端的边缘，会把两个终端合并为一个分屏标签。每个分屏标签单独保存窗格、比例和最近使用的终端；点击其他标签时切换整个工作区，再点击分屏标签可恢复布局。可以同时保留多个分屏组合，每组最多 4 个窗格。

拖动窗格标题可调整位置；拖到中心交换或替换终端。标签上的「解除分屏」恢复独立标签，窗格上的「收起」把该终端移回独立标签，两者都不会断开会话。组合标签上的关闭按钮会关闭此组合的全部会话。

手机上使用标签左侧的拖动柄，按住后拖到终端上方或下方分屏；也可点击「终端布局」选择窗格。滚动标签和终端输出不会触发分屏拖拽。

手机连接后使用紧凑控制栏，点击全屏按钮隐藏导航与标签行。Android 11+ 同时隐藏系统栏，边缘滑动可临时唤出；Android 9/10 保留系统状态栏，以保持软键盘自动调整高度。返回键先退出全屏。

全屏或软键盘打开时，分屏组合优先显示当前终端；通过顶部下拉框切换组内窗格或其他终端，退出全屏并收起键盘后恢复布局。辅助按键保留在软键盘上方，更多操作集中在右上角菜单。
